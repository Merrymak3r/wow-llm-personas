# Tips:
#  - The FILE NAME (lowercase) must match the bot's in-game character name:
#    a bot named "Thorgrim" loads personas/thorgrim.txt.
#  - ~60-100 words works best. Small models drift if you over-write it.
#  - The "under 25 words / never break character" tail matters -- it keeps replies
#    short and stops the model from narrating or slipping out of the role.
#  - Vanilla names are letters-only and <=12 chars, so aliases like r2d2 -> "artoo".
